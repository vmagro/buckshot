# Buck2 Helpers

A collection of Buck2 helpers: buck2-prelude, toolchains, and utility scripts.

## Structure

- `buck2-prelude/` — Facebook's buck2 prelude pulled as a git subtree
- `buckshot/` — This repo's own maintenance CLI (a `rust_binary`, `clap` subcommands `npm buckify` and `rust toolchain`) — see `buckshot/README.md`
- `third-party/BUCK`, `third-party/npm/` — External dependencies via http_archive (npm packages generated by `buckshot npm buckify` — see `third-party/npm/README.md`)
- `third-party/rust/` — Rust third-party crates, vendored via `reindeer` (checked-in `BUCK`, `Cargo.toml`/`Cargo.lock`, `fixups/`) — used by `buckshot/` itself
- `toolchains/BUCK` — Toolchain definitions, resolved at the well-known `toolchains//:<name>` targets
- `rust/toolchain/` — Hermetic rust toolchain: generated `BUCK` + rule definitions (`rust_dist.bzl`), regenerated by `buckshot rust toolchain` — see `rust/toolchain/README.md`
- `platforms/` — Target platform definitions (`macos-aarch64`, `linux-x86_64`, `linux-aarch64`, `windows-x86_64`) for `--target-platforms`
- `platforms/exec/` — A container-based NativeLink remote-execution worker that lets Rust builds cross-compile for Linux from macOS — see `platforms/exec/README.md`
- `tests/` — Test suites and test utilities

## Toolchain Generation

To generate the rust toolchain's `BUCK` file from a rustup dist channel TOML:

```bash
buck2 run //buckshot -- rust toolchain --channel-toml <url-to-channel-rust-nightly.toml>
```

See `rust/toolchain/README.md` for the full generator docs, and `buckshot/README.md` for the CLI itself.
