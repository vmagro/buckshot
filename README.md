# Buck2 Helpers

A collection of Buck2 helpers: buck2-prelude, toolchains, and utility scripts.

## Structure

- `buck2-prelude/` — Facebook's buck2 prelude pulled as a git subtree
- `third-party/BUCK`, `third-party/npm/` — External dependencies via http_archive (npm packages generated by `third-party/npm/npm_buckify.py`)
- `toolchains/BUCK` — Toolchain definitions, resolved at the well-known `toolchains//:<name>` targets
- `toolchains/rust/` — Hermetic rust toolchain: generated `BUCK`, rule definitions (`rust_dist.bzl`), and the generator (`gen_rust_toolchain.py`) — see `toolchains/rust/README.md`
- `tests/` — Test suites and test utilities

## Toolchain Generation

To generate the rust toolchain's `BUCK` file from a rustup dist channel TOML:

```bash
python3 toolchains/rust/gen_rust_toolchain.py --channel-toml <url-to-channel-rust-nightly.toml>
```

See `toolchains/rust/README.md` for the full generator docs.
